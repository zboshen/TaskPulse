# 发布文案

## 中文

做了一个很小的 macOS 工具：**TaskPulse · 任务脉搏**。

让 Codex 放手去做，让任务进度留在眼角。屏幕边缘的一张小卡片，最多跟进 5 个任务：进行中优先、最新优先，完成结果只在未读时出现，读过就自动消失。

它用 Swift 原生构建，无 Electron、无独立服务端，支持主副屏吸附、拖动位置与大小、一键新建 Codex 聊天、开机启动，以及隐藏 Dock。

外观和动效受到 CodeNotch 的启发，复用的 MIT 代码已保留致谢与许可。我们的方向更专注：把本机 Codex 任务跟进做得轻一点、顺手一点。

已开源并提供 macOS 安装包，欢迎试用、Star，或 Watch → Releases 订阅后续更新：
https://github.com/zboshen/TaskPulse

首版未经过 Apple 公证，使用的是本机状态适配，具体兼容范围和隐私说明见仓库。

## English

Meet **TaskPulse** — a small native macOS widget that keeps local Codex tasks at your screen edge.

Up to five tasks. Running work first, unread results next. Read it, and it disappears. Drag to move or resize, choose your display, and open a new Codex chat in one click.

SwiftUI + AppKit. No Electron. No separate backend. Inspired by CodeNotch, with MIT attribution preserved.

Open source, with a macOS download. Star the project or watch Releases for updates:
https://github.com/zboshen/TaskPulse

The initial release is ad-hoc signed, not notarized. See the repository for privacy and compatibility details.
